# tools/

Sem patří **portable ExifTool pro Windows** (není součástí gitu).

1. Stáhněte „Windows Executable“ z https://exiftool.org/ (např. `exiftool-13.xx_64.zip`).
2. Obsah ZIPu rozbalte sem, tj. vznikne:
   ```
   tools\exiftool(-k).exe
   tools\exiftool_files\      <-- nutná složka (Perl + knihovny), neodstraňovat!
   ```
3. Soubor `exiftool(-k).exe` **přejmenujte na `exiftool.exe`** (jinak čeká na stisk klávesy).
4. V aplikaci v postranním panelu musí svítit 🟢 ExifTool s číslem verze.
